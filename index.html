Zero-Server PDF Reader (v6 – Sök, PDF-Badges, Svarstrådar & Live-Synk)

  1. Skriv ditt namn i rutan User längst upp till vänster.
  2. Klicka på 🔄 1A. Live Sync Folder (kräver Chrome/Edge över https:// eller http://localhost) för att koppla en gemensam mapp med automatisk bakgrundssynk och direktsparning.
  3. I rullgardinsmenyn för PDF-filer ser du direkt en badge för varje dokument: 🟠 (X öppna / Y) eller ✅ (Y klara).
  4. Använd sökfältet och filtren högst upp i sidopanelen för att söka i fritext bland kommentarer och svar, eller filtrera på granskare och status.
  5. Klicka på 💬 Svara på ett kort för att svara i tråden eller välj ✓ Svara & Klara för att bocka av punkten direkt.
